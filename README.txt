SUVOJIT PAL PORTFOLIO — VS CODE VERSION

Files:
- index.html  -> main website
- style.css   -> all existing styling
- script.js   -> existing JavaScript
- images/     -> certificate images extracted from the original HTML

How to run:
1. Open this folder in VS Code.
2. Open index.html.
3. Use Live Server if you have it installed, or open index.html directly in a browser.

Nothing about the website content/design/functionality was intentionally changed;
the original inline CSS, JavaScript, and embedded certificate images were separated
into normal project files so the project is easier to edit in VS Code.
